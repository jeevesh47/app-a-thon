# Appathon Edge Master

Create a modern, high-converting, single-page event website for a technical coding competition called **APP"A"THON**.

### Design Inspiration & Style

Take strong inspiration from these three websites:

- https://code2create.acmvit.in/ (dark cinematic aesthetic, elegant typography, floating navigation, beautiful hero section with subtle animations)

- https://hack26.ieeemace.org/ (futuristic/dark mysterious vibe, strong typography, atmospheric feel)

- https://www.dsudevhack3.tech/ (clean modern layout, bold headlines, clear sections, good use of cards and CTAs)

Overall style:

- Dark theme with deep navy/black background

- Accent colors: electric cyan, soft purple, and magenta gradients

- Clean sans-serif fonts (Inter / Space Grotesk / Outfit style)

- Smooth scroll animations, subtle particle or glow effects

- Glassmorphism cards, soft glows, and modern micro-interactions

- Fully responsive (mobile-first)

### Branding

Event Name: **APP"A"THON**

Tagline: "Code the Edge. Master the Exceptions."

Short description: A technical coding challenge where participants develop solutions while focusing on identifying, handling, and presenting edge cases.

### Required Sections (in this order)

1. **Hero Section**

   - Large bold title: APP"A"THON

   - Tagline underneath

   - Short one-liner about the event

   - Primary CTA button: “Register Now”

   - Secondary button: “View Problem Statement” (placeholder)

   - Subtle animated background (code particles / abstract tech feel)

2. **About the Event**

   - Explain the unique concept clearly:

     APP"A"THON is a coding-based technical challenge where participants receive a problem statement and must develop a working solution with special focus on edge cases and exceptional scenarios.

   - Highlight that the final evaluation includes a mandatory PPT presentation of the “Edge Case Model”.

3. **How the Event Works** (Step-by-step cards)

   1. Problem Statement

   2. Coding & Implementation

   3. Edge Case Identification

   4. Output Generation

   5. Edge Case Model

   6. Mandatory PPT Presentation

4. **Edge Case Focus** (Highlight section)

   List common edge cases participants should consider:

   - Empty or null input

   - Minimum / Maximum values

   - Duplicate values

   - Invalid inputs

   - Boundary conditions

   - Unexpected combinations

   - Large-scale inputs

5. **Edge Case Model** (What participants must present)

   Explain the structure of the mandatory PPT:

   - Problem scenario

   - Normal-case logic

   - Identified edge cases

   - Expected vs Actual output

   - How the code handles each edge case

   - Improvements / Optimizations

6. **Timeline / Schedule** (placeholder timeline with phases)

7. **Prizes & Recognition** (placeholder prizes section with attractive cards)

8. **Registration Section**

   - Clear “Register Now” button

   - Team size, eligibility (placeholder)

9. **FAQs** (accordion style)

   Include relevant questions about the format, presentation, languages allowed, etc.

10. **Footer**

    - Event name + tagline

    - Social links placeholders

    - Contact email placeholder

    - “Organized by [Your Club/College Name]”

### Technical Requirements

- Use modern React + Tailwind CSS (Lovable’s default stack is fine)

- Smooth scroll and section animations

- Sticky/floating navigation bar

- Good visual hierarchy and generous spacing

- Make the website look premium and professional — something that feels like a flagship technical event

Generate a complete, beautiful, production-ready landing page.
